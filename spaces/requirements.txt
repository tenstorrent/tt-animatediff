# Space runtime.

# gradio is pinned exactly and MUST match sdk_version in README.md — the Hub builds
# against sdk_version, so a drift between the two means the Space runs a different
# Gradio than this file claims.
gradio==6.26.0
#
# THIS FILE USED TO CARRY FOUR COMPATIBILITY CAPS, and they are worth knowing about
# because re-adding one is the obvious wrong fix for the next gradio breakage.
#
# Under gradio 4.44.1 the Space needed python_version 3.12 (3.13 dropped stdlib audioop,
# which gradio's pydub imports), huggingface_hub<1 (gradio's oauth.py imports HfFolder,
# removed in 1.0), pydantic<2.11 (gradio-client 1.3.0's schema walker assumes
# additionalProperties is a dict) and starlette<1 (gradio called TemplateResponse in the
# pre-0.29 positional order). Every one fixed a real deploy failure.
#
# Together they also froze the stack below its security floors. Cycode flagged
# starlette 0.52.1 (CVE-2026-54283, -48818 HIGH; -48710, -48817 MEDIUM) and
# transformers 4.57.6 (CVE-2026-9856, -5241, -4372 HIGH; -1839 MEDIUM), and there is no
# CVE-free version inside either cap: every fix ships in starlette 1.x and
# transformers 5.x. Propping up a 2024-era gradio was buying compatibility with
# vulnerabilities.
#
# gradio 6 wants precisely the fixed versions — it declares starlette>=1.0.1,
# huggingface-hub>=1.16.0, pydantic>=2.0, and pulls audioop-lts on 3.13 — so the caps
# left with the pin that needed them. Verified before shipping: page renders and a real
# generation completes (see the launch-and-fetch note at the bottom).
#
# What remains are FLOORS, not caps, and each names what it protects against.
#
# starlette's four CVEs are fixed across 1.0.1/1.1.0/1.3.1, so 1.3.1 is the floor that
# covers all of them. gradio 6 allows >=1.0.1, which would still admit two of them.
starlette>=1.3.1
#
# transformers' highest fix is 5.10.0. <6 keeps the major this is exercised against.
transformers>=5.10,<6
#
# huggingface_hub 1.x is what gradio 6 and diffusers 0.40 both require.
huggingface_hub>=1.16,<2
#
# diffusers keeps its tested range: 0.32.1 as the floor, 0.39.0 and 0.40.0 verified.
diffusers>=0.32.1,<0.41
accelerate>=0.20.0,<2
torch>=2.0.0
safetensors>=0.4.0
Pillow>=9.0.0
numpy>=1.24.0
